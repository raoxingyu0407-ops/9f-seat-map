# 9F 工位平面图

一个无需后端的交互式座位表网页，支持：

- 点击座位填写或修改人员姓名
- 按姓名或座位号搜索
- 自定义浮标颜色和区域名称
- JSON 导入、导出和本地备份
- 打印或另存为 PDF
- 明暗主题及移动端布局

网页首次打开时会载入 2026-07-15 更新的默认座位安排，访问者仍可自行修改、清空或导入其他安排。

## 隐私说明

网页不会把人员安排上传到服务器。输入的数据只保存在当前访问者浏览器的 `localStorage` 中，清除浏览器网站数据后会消失。需要长期保存时，请使用页面中的“导出”功能下载 JSON 备份。

## 本地预览

直接用浏览器打开 `index.html` 即可。

## GitHub Pages

本项目是纯静态单页，发布源设置为默认分支根目录即可。
